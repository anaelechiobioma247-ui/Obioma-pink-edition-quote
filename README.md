# Obioma Pink Edition — Quotes & Inspiration

A separate, offline-first mobile quote experience built with React Native and Expo.

## Features

- Mood-based quote browsing
- Fast local search
- Saved favorites with offline persistence
- Quote story/detail screens
- Q&A discussion area
- Pink, mobile-first interface

## Run locally

```bash
npm install
npm start
```

Android:

```bash
npm run android
```
