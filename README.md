# Obioma Pink Edition — Quotes & Inspiration

A separate, offline-first mobile quote experience built with React Native and Expo.

## Features

- Mood-based quote browsing
- Fast local search
- Saved favorites with offline persistence
- Quote story/detail screens
- Q&A discussion area
- Pink, mobile-first interface

## Run locally

```bash
npm install
npm start
```

Android:

```bash
git clone https://github.com/anaelechiobioma247-ui/Obioma-pink-edition-quote.git
cd Obioma-pink-edition-quote
npm install
npx eas-cli login
npx eas-cli build:configure
npx eas-cli build --platform android --profile preview
```
